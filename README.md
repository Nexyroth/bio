## 🎭 Về DUALITY

DUALITY là một portfolio cá nhân được thiết kế theo concept **hai danh tính song song**:

- **BẢO** — Chính mình: học sinh lớp 11, game thủ, người thích nhạc phonk và những buổi tối yên tĩnh.
- **NEXYROTH** — Nhà xây dựng: thử nghiệm AI, viết code, làm game, khám phá công nghệ.

Hai mode không chỉ là hai bảng màu — chúng là hai thế giới riêng biệt với hệ thống điều hướng, typography, animation và không khí hoàn toàn khác nhau, được kết nối bằng một transition điện ảnh.

---

## ✨ Điểm nhấn

- 🎬 **Cinematic identity transition** — wipe 5 cột gradient + SVG morph + particle burst
- 📜 **Continuous scroll narrative** — cuộn liền mạch, không cần click tab
- 🌐 **WebGL hero** — Three.js scene cho cả hai identity
- ⌨️ **Command palette** — Ctrl/Cmd + K để điều hướng nhanh
- 🎨 **Kinetic typography** — marquee, scramble, glitch, SplitText
- 🖱️ **Custom cursor + effects** — desktop only (jelly cursor, gravity trail, liquid distortion)
- 📱 **Mobile-first UX** — safe-area, bottom-sheet palette, touch-optimized
- ♿ **Accessibility** — WCAG AA contrast, reduced-motion tiering, keyboard navigation
- 🥚 **Easter egg** — gõ "duality" ở đâu đó

## 🛠️ Tech Stack

| Lớp | Công nghệ |
|---|---|
| Framework | React 18 + TypeScript |
| Build | Vite |
| Styling | CSS Modules + design tokens |
| Animation | GSAP (ScrollTrigger, SplitText, Flip, MorphSVG, Observer) |
| Smooth scroll | Lenis |
| 3D | Three.js + React Three Fiber + Drei + Postprocessing |
| Fonts | Fraunces, Be Vietnam Pro, Space Grotesk, JetBrains Mono (self-hosted) |
| Hosting | GitHub Pages |

## 📁 Về repository này

Repo `bio` chứa **build output** (static files) được serve bởi GitHub Pages.

- **Source code** được giữ riêng để maintain và develop
- **`dist/`** được build từ source rồi push vào repo này
- Cấu trúc: `index.html` + `assets/` + `favicon.svg` + `.nojekyll`

Nếu bạn muốn build từ source, cần clone repo source (không public).
